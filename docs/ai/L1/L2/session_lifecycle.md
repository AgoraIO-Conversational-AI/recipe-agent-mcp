# Deep Dive — Session Lifecycle

**When to Read This:** You are touching client-side join/renewal/teardown, debugging RTC/RTM connection issues, or trying to understand how the browser orchestrates the agent session. For the high-level picture, start at [02_architecture](../02_architecture.md).

## Browser orchestration sequence

```
LandingPage
  1. getConfig()             → GET /api/get_config
                               ← { app_id, token, uid, channel_name, agent_uid }
  2. RTM login               (agora-agent-client-toolkit; uses app_id + token)
  3. startAgent()            → POST /api/startAgent { channelName, rtcUid, userUid }
                               ← { agent_id, channel_name, status: "started" }
  4. store agent_id

ConversationComponent
  5. RTC join channel        (publish mic track)
  6. Listen for RTM events:
     - AgentState changes    → visualizer state
     - transcription events  → transcript panel
     - metrics events        → metrics panel
  7. On disconnect / stopAgent:
     → POST /api/stopAgent { agentId }
     → RTC leave + RTM logout
```

## `getConfig` → token

`GET /api/get_config` mints a Token007 RTC+RTM token for a concrete non-zero UID:

- If `uid` query param is missing or ≤ 0, the backend generates a random UID (1000–9999999).
- Returns `uid` as a string; the web client converts to `Number(uid)` for the RTC join.
- The `agent_uid` is also generated by the backend (8-digit random); passed as `rtcUid` in `startAgent`.

## `startAgent` body fields

```typescript
{ channelName: string, rtcUid: number, userUid: number }
```

- `rtcUid` = the agent's UID (from `config.agent_uid`).
- `userUid` = the user's UID (from `config.uid`).
- Both must be positive integers; the backend validates and returns 400 if not.

## Transcript normalization

`normalizeTranscript` in `web/src/lib/conversation.ts` maps `uid === '0'` to the local user UID. This is required because some transcription events arrive with `uid: "0"` before the speaker is confirmed. Preserve this mapping — do not heuristically guess speakers.

## Stop flow

`stopAgent(agentId)` calls `POST /api/stopAgent { agentId }`. The backend's `Agent.stop()` tries the in-memory session first (`_sessions[agent_id]`), then falls back to `client.stop_agent(agent_id)` if the session was lost.

After `stopAgent` returns, the browser leaves the RTC channel and logs out of RTM.

## AgentState → visualizer

`mapAgentVisualizerState()` in `conversation.ts` maps SDK `AgentState` + connection state to the `AgentVisualizerState` expected by `agora-agent-uikit`:

| Condition | Visualizer state |
| --- | --- |
| DISCONNECTED / DISCONNECTING | `disconnected` |
| CONNECTING / RECONNECTING | `joining` |
| Agent not joined yet | `not-joined` |
| `listening` | `listening` |
| `thinking` | `analyzing` |
| `speaking` | `talking` |
| `idle` / `silent` | `ambient` |
